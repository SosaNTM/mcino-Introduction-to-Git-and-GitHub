# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements and ideas are welcome.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change (`git checkout -b my-feature`).
3. Make your changes and commit them with a clear message.
4. Push the branch to your fork (`git push origin my-feature`).
5. Open a pull request against the `main` branch of this repository.

## Bug reports

When reporting a bug, please include:

- a short description of the problem
- the steps needed to reproduce it
- what you expected to happen and what happened instead

## Documentation improvements

Fixes to typos, unclear wording or missing explanations in the documentation are just as welcome as code changes.

## Code of conduct

By participating in this project you agree to follow the `CODE_OF_CONDUCT.md`.
