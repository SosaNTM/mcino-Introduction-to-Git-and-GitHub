A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

Output

# Simple Interest Calculator

Progetto finale del corso *Introduction to Git and GitHub*.

## Descrizione del progetto
Questo progetto contiene uno script Bash (`simple-interest.sh`) che calcola
l'interesse semplice a partire dall'input dell'utente.

## Formula
Interesse semplice = (Capitale x Tasso x Tempo) / 100

## Campi di input
- **Capitale (P)**: somma di denaro investita o prestata
- **Tasso di interesse (R)**: tasso annuo in percentuale
- **Periodo di tempo (T)**: durata in anni

## Output
Lo script stampa a schermo l'interesse semplice calcolato sui valori inseriti.
